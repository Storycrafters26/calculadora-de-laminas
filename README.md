# Calculadora de Láminas

Herramienta para calcular cuántas láminas de plywood 4 × 8 pies necesitas para un mueble.

- Acomoda las piezas automáticamente para aprovechar al máximo cada lámina.
- Separa las piezas por grosor: cada grosor se acomoda en sus propias láminas.
- Lista de partes, presupuesto y cotización en PDF.
- Medidas en pulgadas (con fracciones, como `24 3/4`) o centímetros.

## Usarla

Ábrela en el navegador: https://storycrafters26.github.io/calculadora-de-laminas/

Todo funciona dentro de `index.html`; no necesita instalación.

## Instalarla como app

- **iPhone / iPad:** abre el enlace en Safari → botón Compartir → **Agregar a inicio**. En el cel aparece como **Pawoc**.
- **Android:** abre el enlace en Chrome → menú ⋮ → **Instalar app**.

Una vez instalada abre a pantalla completa y funciona sin internet.

Al cambiar `index.html`, sube `VERSION` en `sw.js` para que los dispositivos instalados tomen la nueva versión.
